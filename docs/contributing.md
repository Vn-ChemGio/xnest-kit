# Contributing

We welcome contributions! Please see our [Contributing Guide](https://github.com/Vn-ChemGio/xnest-kit/blob/master/CONTRIBUTING.md) for details.

## Quick Start

1. Fork the repository
2. Create a feature branch: `git checkout -b feat/my-feature`
3. Make your changes
4. Run tests: `npm run test`
5. Commit using conventional commits: `git commit -m "feat: add my feature"`
6. Push and create a PR

## Development

```bash
# Install dependencies
npm install

# Build
npm run build

# Lint
npm run lint

# Test
npm run test
```

## Commit Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` - New feature
- `fix:` - Bug fix
- `docs:` - Documentation
- `test:` - Tests
- `chore:` - Maintenance
